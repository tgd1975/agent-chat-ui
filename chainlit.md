# agent-chat-ui

A Python chat console powered by a **model-agnostic agent** (Pydantic AI) — it
can use **Agent Skills** (the open `SKILL.md` standard) and your **MCP servers**,
with the underlying LLM made configurable through a **LiteLLM** proxy.

Type a message to get started. Tool and skill calls show up as collapsible steps.
